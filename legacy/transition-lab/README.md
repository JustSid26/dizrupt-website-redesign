# Dizrupt transition lab

Open `index.html` to compare five isolated intro-to-project transition studies.

1. **Continuity Drift** — DIZRUPT recedes toward the brand while the live spiral resolves.
2. **Shared Frame** — a particle outline establishes the project window before expansion.
3. **Lateral Handoff** — one controlled leftward camera move connects both scenes.
4. **Depth Rack** — a focus pull reveals the already-moving project window.
5. **Soft Iris** — a restrained centre reveal opens onto the continuous particle field.

Controls: click **Run transition**, scroll down, or press Space/Enter/Down. Press **R** to replay.

These files do not alter the production homepage transition.
